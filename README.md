# Sentimentul știrilor
   [![DOI](https://zenodo.org/badge/DOI/10.5281/zenodo.23418996.svg)](https://doi.org/10.5281/zenodo.23418996)

**Indici ai sentimentului presei românești despre economie** · 🌐 [sentimentulstirilor.ro](https://sentimentulstirilor.ro) · 🇬🇧 [English](https://sentimentulstirilor.ro/en)

Sentimentul știrilor măsoară cât de pozitiv sau negativ scrie presa românească despre economie. Sistemul colectează articole din peste 130 de publicații (aproximativ 3,5 milioane de articole), le curăță, le scorează cu metode de procesare a limbajului natural (NLP) și agregă rezultatele în indici.

Este proiectul în care aplic cercetarea din doctoratul meu în Finanțe, la Academia de Studii Economice din București.

## Metodologie, pe scurt

1. **Colectare**: articole economice din presa online românească, cu data publicării și sursa.
2. **Curățare**: extragerea textului, eliminarea duplicatelor, normalizarea diacriticelor (ș/ț cu virgulă).
3. **Scorare**: mai multe metode de sentiment (lexicale și modele de limbaj rulate local), comparate între ele.
4. **Agregare**: indici pe zi, săptămână și lună; scor z față de media întregii perioade.

Detaliile complete sunt pe [pagina lucrării](https://sentimentulstirilor.ro/lucrare).
